# School Sphere Platform 🎓

Enterprise School Management & Academic Administration Platform built with Next.js 16 (Turbopack), Tailwind CSS, Framer Motion, TanStack Query, and Prisma.

## ✨ Features

- 🏛️ **Public Campus Page**: Interactive hero, statistics, dynamic departments showcase, interactive FAQ accordion, smooth auto-scrolling capabilities.
- 📊 **Multi-Role Dashboards**:
  - **Admin Hub**: Overview of active students, teachers, parents, classes, and system analytics.
  - **Teacher Portal**: Class management, grading, timetable, and attendance tracking.
  - **Student Portal**: Enrolled subjects, exam routines, results, and assignment submissions.
  - **Parent Portal**: Linked children oversight, academic performance tracking, and direct teacher contacts.
- ⏰ **Interactive Timetable & Visual Clock**: Screen-centered interactive calendar and analog visual clock for date & time selection.
- 👨‍👩‍👧 **Parent-Child Assignment**: Interactive multi-select student linking with live badge management.
- 🎨 **Premium Aesthetic**: Responsive Light and Dark mode with custom typography, vibrant glassmorphism, and micro-animations.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm / yarn / pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/MdShamim5669/School-Sphere.git

# Navigate to the workspace
cd School-Sphere

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (App Router & Turbopack)
- **Styling**: Vanilla CSS / Tailwind CSS v4
- **State & Data**: TanStack React Query v5
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Notifications**: Sonner
